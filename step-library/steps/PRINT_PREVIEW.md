# PRINT_PREVIEW

Triggers the print design preview functionality

## At a glance
- **Category** Browser

## When to Use

Use **PRINT_PREVIEW** to open the active document print-design preview.

## Data Flow

Does not read or write flow context.

## Examples

### Open print preview
```yaml
- step: PRINT_PREVIEW
```
